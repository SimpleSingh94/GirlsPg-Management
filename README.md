# Girls PG Management System

A web-based Girls PG Management System designed to provide a safe, comfortable and convenient accommodation experience for students and working women.

## Features

- 🏠 Room vacancy checking
- 🛏️ Single, Double and Triple Seater rooms
- 👩‍🤝‍👩 Roommate matching based on lifestyle preferences
- 📋 Online booking request
- 🔐 Resident verification and guardian details
- 🍽️ Food and mess preferences
- 🛡️ 24x7 security and safety features
- 📶 High-speed Wi-Fi
- 🧹 Daily housekeeping
- 🧺 Laundry facility
- ⚡ Power backup
- 🤖 AI-based vacancy prediction interface

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Database
- MySQL
- MySQL2

## Main Modules

### 1. Room Vacancy Management
Users can check available rooms and beds based on:
- Room type
- Floor
- Required date
- Vacancy status

### 2. Room Booking
Users can submit their booking request by providing:
- Personal details
- Contact information
- ID verification
- Guardian details
- Room preference
- Move-in date
- Food preference

The booking form supports Single, Double and Triple Seater options. :chatgpt-content-reference{index="0"}

### 3. Roommate Matching
The system matches users based on lifestyle preferences such as:
- Food preference
- Sleep schedule
- Cleanliness
- Study/Work habits
- Noise level
- Visitors
- Occupation

The matching system uses weighted preferences to calculate compatibility. :chatgpt-content-reference{index="1"}

### 4. Facilities Management

The PG provides facilities such as:
- Furnished rooms
- High-speed Wi-Fi
- Daily housekeeping
- Study room
- Mess & meals
- RO drinking water
- 24x7 security
- CCTV surveillance
- Visitor log
- Fire safety
- Laundry
- Power backup
- Hot water
- Parking
